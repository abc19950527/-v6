# 药品进销存管理系统 v6 - Android App

基于Kivy框架开发的Android离线应用，支持药品销售、库存管理、会员管理等核心功能。

## 功能特性

### 核心功能
- **销售开单**: 支持扫码/手动输入药品、自动计算金额、多种支付方式
- **库存查询**: 实时库存显示、支持多条件搜索、库存预警
- **效期预警**: 180天效期预警提醒、支持按期限筛选
- **会员管理**: 会员注册、积分管理、余额充值、折扣设置
- **数据同步**: 支持与电脑端数据同步、备份与恢复
- **小票打印**: 58mm热敏打印机支持、小票重打功能

### 技术特性
- **离线使用**: SQLite本地数据库，无网络也能正常工作
- **快速响应**: 本地数据处理，操作流畅
- **简洁界面**: 医疗蓝(#1890ff)+简约白风格，大按钮触摸友好
- **竖向布局**: 专为手机竖屏优化，适合店员快速操作

## 技术栈

- **框架**: Kivy 2.1.0
- **数据库**: SQLite3
- **打包工具**: Buildozer
- **Python版本**: Python 3.8+

## 安装与打包

### 环境准备

1. 安装Python 3.8+
2. 安装Buildozer:
```bash
pip install buildozer
```

3. 安装Android SDK和NDK (Buildozer会自动下载)

### 打包APK

```bash
# 初始化Buildozer
buildozer init

# 打包Debug版本
buildozer debug

# 打包Release版本
buildozer release
```

### 安装到设备

```bash
# 通过USB安装
adb install bin/*.apk

# 或通过Buildozer直接安装
buildozer debug deploy run
```
